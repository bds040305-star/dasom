# Dasom Portfolio

GitHub Pages 업로드용으로 정리된 포트폴리오입니다.

## 구조
- `index.html` : 메인 포트폴리오
- `css/` : 기존 스타일을 순서대로 분리한 CSS
- `js/` : 인터랙션/라우팅 스크립트
- `assets/images/` : 프로젝트 로고와 포트폴리오 이미지 자산
- `404.html` : GitHub Pages에서 직접 진입 시 안전하게 메인을 보여주기 위한 복사본

## GitHub Pages 배포
1. 저장소의 루트에 이 폴더 안 파일을 전부 업로드합니다.
2. GitHub 저장소 → Settings → Pages
3. Build and deployment에서 `Deploy from a branch` 선택
4. Branch를 `main`, Folder를 `/(root)` 선택 후 Save
5. 배포 완료 후 `https://아이디.github.io/저장소명/` 접속

## 주의
- `index.html`, `css`, `js`, `assets`의 상대 경로 구조를 바꾸지 마세요.
- Pretendard/SUIT/Devicon/GSAP은 CDN을 사용하므로 인터넷 연결이 필요합니다.
- 프로젝트 캡처/목업은 실제 작업 증빙 이미지이므로 이미지 asset으로 유지되어 있습니다. UI와 인터랙션 구조는 HTML/CSS/JS 코드입니다.
